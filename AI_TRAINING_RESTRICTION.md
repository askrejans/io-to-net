# AI Training Restriction

SPDX-License-Identifier: GPL-3.0-only WITH AI-training-prohibited

The source code of this repository may not be used for training,
fine-tuning, or improving machine learning models, large language models,
or similar artificial intelligence systems without explicit written
permission from the author.

This restriction applies to:

- dataset collection
- model training
- model fine-tuning
- reinforcement learning
- automated code ingestion for training datasets

This includes both commercial and non-commercial AI systems.

Allowed usage includes:

- compiling the software
- modifying the software
- running the software
- contributing improvements
- educational use
- research unrelated to training AI systems

This restriction does not affect the permissions granted by the
GNU General Public License for normal software usage.

If you wish to use this project in AI training datasets, you must obtain
explicit written permission from the project author.

Contact:
project maintainer via repository contact methods.

---

## Rationale

Large open-source projects are increasingly being used to train
machine learning systems without the consent of authors.

This restriction ensures the code is used for its intended purpose
as software infrastructure rather than as training material for
AI systems.
